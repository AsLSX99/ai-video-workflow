# 分工表与四线程角色

## 标准分工（本 skill 采用，Codex 为导演）

| 角色 | 负责 |
|---|---|
| 我（人） | 选方向、确认画风、批准花钱；看动态、听声音 |
| Codex（总导演 + 画师） | 写故事和分镜，写所有提示词，画设定图、样帧和每个镜头的首尾帧，抽帧放大检查每张图和每段视频，写 ffmpeg/Python 代码做后期 |
| Seedance（动画师） | 把首尾帧变成几秒钟的视频 |
| 独立审核会话 | 每关新开一个全新会话：只挑错，不改文件，只拿当前关卡材料，不拿任何结论 |

> 原文采用 Claude 当导演、Codex 只当画师（"如果你就是 Codex，就用你自己的生图工具"——原文本身就给了 Codex 导演的口子）。国内用不了 Claude 的场景直接按上表执行，流程和提示词一字不改。

## 四线程角色（templates/09，进阶可选）

| 角色 | 负责什么 |
|---|---|
| 主做 | 负责所有制作 |
| 审核 | 每一步都检查，提交生成视频之前必须写"通过" |
| 监督 | 把我说过的所有话列成清单，盯着大家有没有忘记 |
| 代理 | 按我平时的选择替我做决定，在我事先同意的预算内批准提交 |

配合顺序：每做完一步 → 交给审核 → 交给监督；有分歧交代理决定；所有决定和花费记进审核记录，用户回来可以推翻任何决定。

## 什么时候用哪套审核

- 日常小片：每步开一个独立审核会话（02 / 06 / 08 三个关卡）够用
- 大预算/长片：上四线程，多一个监督管要求清单、一个代理管预算审批
